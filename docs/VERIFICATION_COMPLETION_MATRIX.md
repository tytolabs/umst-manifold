### How to use this matrix

- **Effort:** **S** ≈ single focused test or doc PR; **M** ≈ one subsystem change with tests; **L** ≈ multi-file / API / performance work spanning milestones.
- **Hooks** are what exists **today** to anchor claims; they do **not** imply the acceptance row is met.
- Regenerate path integrity after editing [`Solver-Status.md`](Solver-Status.md): `python3 scripts/check_solver_status.py --check-paths` (from `umst-manifold/`).

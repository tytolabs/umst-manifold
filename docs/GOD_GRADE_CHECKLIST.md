## Performance budget (inference hot path)

Targets are **engineering budgets** for the policy gateway + scalar gates, not WCET certificates.

| Stage | Budget | Notes |
|-------|--------|-------|
| Cartridge `compute_topology` | Dominates step | Burn reductions; keep batch on device |
| CBF `verify_tensor_update` | **≤ 2 deliberate `.into_scalar()` syncs** per topology step | `info_gain.sum()` + `d_int.sum()` only (see `src/ai/cbf.rs`) |
| Host `GateEvaluator` (CD / mix) | **O(1) `f64` predicates** per transition | No tensor materialization in `thermo_transition` |
| Catalog witness (`formal-witness`) | **O(32) byte compare** when digest set | Off by default in dev |
| HTTP `gate_server` | **Cold path** | Not on training loop; feature `gate-server-bin` |
| Lean export / `lake build` | **CI / release only** | Never linked into `libumst_manifold` |

**Anti-patterns (reject in review):** per-voxel `.into_scalar()` in the gateway loop; spawning Lean/lake from `ManifoldGateway`; blocking on witness JSON parse in the inner training step.

## When Lean export changes

1. `make lean-catalog-export` in `umst-formal-double-slit`.  
2. Bump `umst-manifold/artifacts/catalog.lock.json`.  
3. Update `CATALOG_MODULE_WIRED` or `ALLOW_UNUSED_CATALOG_IDS` if module count shifts.  
4. `cargo test --test catalog_all_ids_registered` + `verify_umst_stack.sh`.

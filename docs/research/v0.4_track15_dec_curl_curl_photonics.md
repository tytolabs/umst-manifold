# Track 15 — DEC vector curl–curl Maxwell (photonics)

Research memo tying frequency-domain electromagnetics to the manifold’s DEC scaffolding, the current **Helmholtz chain** photonics path, and a phased implementation plan. Primary references: Hirani (DEC foundations) and Desbrun et al. (SIGGRAPH DEC course) as cited in [`docs/Mathematical-Foundations.md`](../Mathematical-Foundations.md).

## 1. Context in `umst-manifold`

- **`PhotonicsHelmholtzSolver::solve_helmholtz`** ([`src/physics/solvers/photonics.rs`](../../src/physics/solvers/photonics.rs)) solves a **scalar** complex Helmholtz stencil on a **single uniform x-monotone path** extracted from `edges_b1` + `coords_n3` (`extract_uniform_x_chain`). RHS uses the TE phasor identity \(-i\omega\mu_0 J\) mapped to real/imag parts; tridiagonal **Thomas** on host; optional PML via complex \(\varepsilon\).
- **`PhotonicsSolver::solve_maxwell_curl_curl`** (same module, `--features photonics`): on a **uniform x-chain** only, solves the **minimal primal-chain DEC** TE \(E_y\) system (same tridiagonal as `solve_helmholtz` + Thomas); **no** production \(d_1\) (edge→face curl) on 2D/3D patches. See module docs in `photonics.rs` and [`apply_dec_te_curl_curl_chain_operator`](../../src/physics/solvers/photonics.rs) for the explicit \(d_0^\top\)–flux–\(d_0\) tensor matvec used in verification tests.
- **DEC primitives today:** [`EdgeTopology`](../../src/physics/topology.rs) (`edges_b1` shape **`[2, E]`** — row 0 all sources, row 1 all targets, row-major flatten), [`dec_primal`](../../src/physics/dec_primal.rs) (`primal_scalar_edge_increment` as oriented \(d_0\), `primal_divergence_from_edge_flux` as \(B_1^\top\)-style scatter), [`dec_operators::DecEdgeOperators`](../../src/physics/dec_operators.rs) (nodal → edge means). **No** production \(d_1\) (edge→face curl) or Hodge \(\star\) operators are wired into photonics yet.
- **Helmholtz / curl–curl tests:** [`tests/verification/photonics_fresnel.rs`](../../tests/verification/photonics_fresnel.rs) builds a 1-D chain, checks `curl_curl_y_mode_matches_scalar_helmholtz` (Thomas path vs `solve_helmholtz`, vacuum \(\varepsilon_r=1\)), `curl_curl_y_mode_matches_scalar_helmholtz_piecewise_eps` (**non-uniform** node \(\varepsilon_r\) along the same chain — locks operator identity under a distinct material pattern), and `dec_te_primal_tensor_matches_chain_stencil` (Burn DEC matvec vs the hand TE stencil).
- **Scope guard:** these agreements are **1-D chain reductions** of the TE \(E_y\) operator (harmonic-mean fluxes on links). They do **not** certify full **2D/3D** curl–curl vs Helmholtz equivalence; production \(d_1\) / `faces_b2` DEC remains unimplemented for photonics (§4).

**Note on docs vs code:** [`Mathematical-Foundations.md`](../Mathematical-Foundations.md) tabulates `edges_b1` as \(|E|\times 2\); the **implemented Burn contract** is **`[2, E]`** (see module docs in `photonics.rs` and `topology.rs`). New DEC Maxwell work should follow **`[2, E]`**.

## 2. Whitney 1-forms, codifferential, and curl–curl

### 2.1 Whitney 1-forms on edges

In smooth FEM, **Whitney 1-forms** are piecewise-linear differential forms associated with mesh edges; their degrees of freedom are naturally **line integrals** \(\int_e \mathbf{E}\cdot d\mathbf{l}\) (edge circulations), not point values at edge midpoints. In **DEC on a simplicial complex**, one often works directly in the **cochain** picture: a **discrete 1-form** is a real (or complex) number per oriented edge, with pullback / Whitney map used when interpolating to the continuum for analysis or visualization (Hirani 2003; Crane et al. 2013).

**Implication for UMST:** storing \(\mathbf{E}\) as **`[B, N, 3]`** nodal vectors is convenient for mechanics-style coupling but is **not** the native DEC 1-cochain DOF. A rigorous DEC curl–curl will either (a) introduce **edge-based 1-form DOFs** (possibly three components projected onto edge tangents), or (b) define a **lifting / restriction** between nodal vectors and edge circulations using the embedded `coords_n3` edge tangents — with explicit care so discrete Stokes and symmetry match the chosen Hodge.

### 2.2 Codifferential

On a chain complex with discrete exterior derivative \(d_k: C^k\to C^{k+1}\), the **codifferential** is \(\delta_{k+1} = \star_k^{-1} d_k^\top \star_{k+1}\) (sign conventions depend on \(k\) and orientation; Hirani normalizes this carefully). Primal–dual DEC uses a **dual mesh** (or circumcentric dual) so that \(\star\) is diagonal or sparse and \(\delta\) is computable as **incidence + Hodge**.

**Weak curl–curl** in phasor form (time-harmonic \(e^{-i\omega t}\)):

\[
\nabla \times (\mu_r^{-1}\nabla\times \mathbf{E}) - \omega^2 \varepsilon_r \varepsilon_0 \mu_0 \,\mathbf{E} = -i\omega\mu_0 \mathbf{J}.
\]

With \(\varepsilon_0\mu_0 = c^{-2}\) and \(k_0 = \omega/c\), this matches the structure **curl curl** \(- k_0^2 \varepsilon_r\) on \(\mathbf{E}\) (up to material tensors and gauging).

### 2.3 Frequency-domain curl–curl: weak FE vs DEC primal/dual

- **Nédélec / edge FE weak form:** seek \(\mathbf{E}\in H(\mathrm{curl})\); test with \(\mathbf{v}\in H(\mathrm{curl})\); natural interface conditions for tangential \(\mathbf{E}\), etc. The nullspace of the curl–curl block (irrotational pure-gradient modes at \(k_0=0\)) is removed by **divergence cleaning**, **penalty**, **current consistency**, or working in a **reduced subspace**.
- **DEC primal/dual:** place \(\mathbf{E}\) in **primal 1-cochains** (or dual 1-cochains depending on formulation); \(\mathrm{curl}\) is **\(d_1\)** mapping edge values to face values (2-cochains on triangles in 2D, or faces in 3D). The **curl–curl** stiffness is schematically \(d_1^\top \star_\mu^{-1} d_1\) composed with \(\star_\varepsilon^{-1}\) on 1-forms and a mass term \(k_0^2 \star_\varepsilon\) (exact placement of Hodge stars follows primal vs dual choice; see Hirani §mixed formulations and Crane notes on **primal–dual** splitting).

**Alignment with current code:** the scalar Helmholtz path is the **1-D reduction** where the only nontrivial component is transverse to the chain and \(\nabla\times\nabla\times\) collapses to a **second difference** with harmonic-mean \(\varepsilon^{-1}\) on half-edges — consistent with FDFD TE, not with a general \(d_1\) operator.

## 3. Alignment with `edges_b1` and Burn tensors

| Object | Typical shape | Role |
|--------|----------------|------|
| `edges_b1` | `[2, E]` `Int` | Oriented \(B_1\): endpoints for gather/scatter (`EdgeTopology`). |
| Nodal field | `[B, N, C]` | Current photonics `e_field`, \(\varepsilon\) per node channel. |
| Edge field | `[B, E, C]` | Natural home for 1-form fluxes / circulations after gather (`primal_scalar_edge_increment` already maps nodal scalars → edge increments `[B,E,C]`). |
| Face incidence | `faces_b2` (when present) | Needed for \(d_1\) and \(\delta_2\); UMST carries this field for sheaf topology — Maxwell **requires** consistent `faces_b2` on 2D/3D patches. |

**Burn implementation pattern:** reuse `EdgeTopology::gather_endpoints` and scatter mirrors of [`primal_divergence_from_edge_flux`](../../src/physics/dec_primal.rs) for \(d_0^\top\); build \(d_1\) as signed face sums using `faces_b2` with the same row-major discipline as `edges_b1`. Material \(\varepsilon\) can start as **per-node** data mapped to edges via `DecEdgeOperators::harmonic_mean_on_edges` (already used for transport-style reductions) or lifted to **face** \(\star\) weights once anisotropic tensors appear.

## 4. Phased plan

### Phase A — **2D simplicial patch** (single triangle / small disk)

1. Fix **orientation rules** for `edges_b1` and `faces_b2` on a manifold disk (`tests/dec_identities.rs::stokes_triangle` is the spirit; promote to **production** incidence helpers).
2. Implement **\(d_0\)** (already), **\(d_1\)** (edge → face), and **\(d_1^\top\)** (face → edge) as sparse gather/scatter or dense patch matrices for unit tests.
3. Build **diagonal Hodge \(\star_1,\star_2\)** from **metric** (edge lengths, face areas from `coords_n3`) following Hirani / Crane.
4. Assemble **2D TM/TE** reduced problems or full in-plane vector unknowns on edges; verify **MMS** and **eigenmode** against analytic disk or rectangle (high leverage before 3D).
5. **Null-space / frequency:** at fixed \(k_0\), system is usually definite; add one test near **resonance** to stress solver. Document **gauge** choice (divergence penalty or pure solenoidal subspace).

### Phase B — **Full 3D**

1. Require **consistent tet/hex** complex: `faces_b2` for surface triangles, plus **volume** incidence (edge→facet / facet→cell) — may exceed current UMST graph if only surface skeleton exists; **extrusion** ([`extruded_plate`](../../src/physics/extruded_plate.rs)) is a candidate seed topology.
2. Implement **Nédélec-like** or **DEC primal** curl–curl with **material \(\mu,\varepsilon\)** (scalar then tensor).
3. Replace `solve_maxwell_curl_curl` branch: **Krylov** (Burn-side CG/BiCGStab on normal equations or direct complex sparse) with **block preconditioners**; retire host-only Thomas except as 1-D fast path.
4. **PML:** coordinate stretching / complex metric on dual cells (research-grade; defer until primal operator is stable).

### Phase C — **Null-space handling**

- **Low-frequency / DC limit:** curl–curl has a large **gradient** nullspace; use **divergence constraint** (\(\delta \varepsilon E = \rho\)), **Lorentz gauge** penalty, or solve for **vector potential** \(A\) with **Calderón** preconditioning in FE literature — DEC analogs use **mixed forms** (Hirani).
- **Topology:** harmonic 1-forms appear on graphs with **cycles**; for Maxwell cavities, **spurious zero modes** must match discrete cohomology dimension — validate with small **torus** / **ring** graphs before production meshes.

## Appendix — Implementation risk notes (for planning)

1. **DOF representation mismatch:** nodal `[B,N,3]` vs true edge 1-forms — without a defined Whitney/lifting map, DEC consistency and adjoint properties are unclear.
2. **`faces_b2` completeness:** curl requires **\(d_1\)**; missing or inconsistent face incidence yields incorrect spectrum and **fake dissipation**.
3. **Hodge stars:** diagonal \(\star\) from circumcentric dual fails on **bad** simplices; need **quality checks** or **barycentric** fallback (extra implementation surface).
4. **Anisotropic \(\varepsilon\):** tensor permittivity needs **metric-aware** mixing on edges/faces, not only `harmonic_mean_on_edges` on scalars.
5. **Solver stack:** Burn lacks native complex sparse direct solvers like production FEM; **iterative** methods on indefinite systems need **preconditioning** and careful **BC** encoding (PEC/PMC).
6. **Adjoint / autodiff:** a full sparse solve in the forward pass complicates the same **“no grad through Thomas”** stance documented for Helmholtz — expect **implicit differentiation** or **detach** boundary for design loops.
7. **PML + DEC:** combining Berenger-style stretching with discrete \(\star\) is non-trivial; risk of **instability** until the primal operator is verified without PML.

# Track 14 — Implicit Newton for Poisson–Nernst–Planck (v0.4)

Research memo tying the **DEFERRAL — Electrochemistry** goals in `docs/Solver-Status.md` to the current `electrochemistry-mvp` implementation: **default** `solve_pnp_step` → explicit Picard (`solve_pnp_step_experimental`); **opt-in** MVP-chain implicit backward Euler + damped Newton via `pnp_implicit_newton_chain: Some(NewtonPnpContext {…})` + `solve_pnp_step_dispatch`, plus regression / Debye harnesses in `tests/verification/pnp_debye_layer.rs`.

## Current discrete backbone (reference)

- **Poisson (path chain):** `try_solve_poisson_chain_thomas` solves the interior tridiagonal system from `poisson_path_dirichlet_thomas`, consistent with the same discrete Laplacian \(\mathcal{L}\) as `TopologicalLaplacian::scalar_laplacian` on the MVP chain (see module docs in `src/physics/solvers/electrochemistry.rs`). End nodes take Dirichlet values from the incoming potential tensor.
- **Poisson (general graph):** explicit relaxation substeps using `lap_phi + rho_over_eps` as a residual (Jacobi-like damped fixed point), not an exact Newton step on \(\Phi\).
- **Nernst–Planck:** Scharfetter–Gummel edge flux with harmonic-mean diffusivity on edges, `pe = z (F/RT) Δ_e φ`, Bernoulli \(B(x)\) via `bernoulli_b`, then `primal_divergence_from_edge_flux_topo` for \(\nabla\!\cdot J\). Explicit Euler mass update \(c^{n+1} = c^n - \Delta t\,\nabla\!\cdot J\) (sign chosen so \(\Phi=0\) recovers the Fickian graph Laplacian — exercised in `sg_zero_field_matches_explicit_fickian_graph_laplacian`).
- **Coupling per explicit step (`solve_pnp_step` → `solve_pnp_step_experimental`):** each Picard sweep is one pass \(\rho_e(c^{(k)})\to \Phi^{(k+1)}\) (Thomas or relaxation), then SG NP with \(\Phi^{(k+1)}\) and trial \(c^{(k)}\) in the flux, while the mass update always anchors on the step’s \(c^n\): \(c^{n+1}=c^n-\Delta t\,\nabla\!\cdot J\) (SG assembly in `solve_pnp_split_step_experimental_with_refs`, called from `solve_pnp_step_experimental`). [`ElectroChemicalSolver::coupling_picard_iters`] repeats that sweep \(k=0\ldots K-1\) with \(c^{(0)}=c^n\) at step entry. **`NewtonPnpContext` is not used on this path** (implicit Newton is **not** merged into `solve_pnp_step_experimental`). **Track 14 (MVP path chain):** host `f64` dense-Jacobian damped Newton on the backward-Euler residual via [`ElectroChemicalSolver::try_solve_pnp_backward_euler_newton_chain`], or the same contract through [`ElectroChemicalSolver::solve_pnp_step_dispatch`] when [`ElectroChemicalSolver::pnp_implicit_newton_chain`] is `Some` (non-chain / ineligible graphs fall back to the explicit Picard path). Tests in `pnp_debye_layer.rs`.

**DEFERRAL acceptance (Electrochemistry):** residual decrease under damped Newton on a 1D benchmark; mass-conservation band on closed graphs; **double-precision option** for large \(|z\Delta\phi|\). **Quasi-steady λ_D gates** (`debye_screening_256_cells_phi_25mv_*`, `debye_screening_256_cells_phi_100mv_*`): both stay **`#[ignore]`** on default CI — the shared harness already uses **`solve_pnp_step_dispatch`** + **`pnp_implicit_newton_chain: Some(…)`** (same opt-in pattern as production); the linear gate needs the full long outer trajectory at **N=256** for the exponential-fit band; the **φ₀=4 V_T** Gouy–Chapman sibling waits on that linear baseline. **`debye_implicit_dispatch_short_horizon_smoke`** (same file) is the **CI-fast** wiring check on a short chain.

## Gummel vs Newton on coupled \((\Phi, c^\pm)\)

| Aspect | Gummel-type decoupling | Picard / operator-split (current direction) | Monolithic Newton (Track 14 target) |
|--------|----------------------|---------------------------------------------|-------------------------------------|
| **Unknowns** | Often \(\Phi\) then \(c_i\) (or vice versa) in sequence | \(\Phi\) from linear Poisson with frozen \(c\); then \(c\) from **explicit** NP | Single vector \(U=[\Phi; c^+; c^-]\) (or log-variables) |
| **Linear solves** | SPD-like Poisson; NP often implicit per species if time-discretised | Thomas SPD on chain for \(\Phi\); NP **explicit** in time | Coupled Jacobian or Newton–Krylov matvec |
| **Convergence** | Outer iterations for coupling only | Outer Picard improves \(\Phi\)–\(c\) lag; still limited for stiff screening | Quadratic (local) with consistent Jacobian and good IC |
| **Stability** | Mild | Limited by explicit NP CFL / stiff drift | Backward Euler / BDF with large \(\Delta t\) possible |

**Picard (documented intent):** fixed-point map \(c \mapsto \mathcal{F}(c)\): assemble \(\rho_e(c)\), solve Poisson for \(\Phi\), advance \(c\) one NP step. Increasing sweeps reduces lag between \(\Phi\) and \(c\) but does **not** remove explicit NP stability limits or guarantee steady-state Debye fits.

**Newton:** impose fully implicit residuals \(R_\Phi(\Phi^{n+1},c^{n+1})=0\), \(R_{c^\pm}(\Phi^{n+1},c^{n+1})=0\) for the chosen time discretisation (e.g. backward Euler \(c^{n+1}-c^n + \Delta t\,\nabla\!\cdot J(\Phi^{n+1},c^{n+1})=0\)). Linearisation yields a sparse coupled system per Newton correction.

## Jacobian structure (monolithic implicit PNP)

Stack ordering example: \([\Phi_0,\ldots,\Phi_{N-1}, c^+_0,\ldots,c^+_{N-1}, c^-_0,\ldots]^T\).

1. **Poisson row block** \( \partial R_\Phi / \partial \Phi \): discrete Laplacian matrix (chain: tridiagonal interior; general graph: DEC/graph Laplacian pattern) plus future variable-\(\varepsilon\) stiffness when implemented.
2. **\(\partial R_\Phi / \partial c^\pm\):** from \(\rho_e = F(c^+-c^-)\) (current minimal model): columns are pointwise multiples of \(F/\varepsilon\) (no spatial stencil in \(c\) for \(\rho_e\) itself).
3. **\(\partial R_{c}/ \partial c\):** NP block: SG flux derivatives w.r.t. endpoint concentrations assemble a **non-symmetric** M-matrix-like sparsity on the graph (backward Euler adds \(I/\Delta t\)).
4. **\(\partial R_{c}/ \partial \Phi\):** SG flux depends on \(B(z\Delta\phi)\) and \(B(-z\Delta\phi)\); derivatives w.r.t. \(\phi_a,\phi_b\) populate couplings between potential nodes sharing an edge and concentration rows for that species.

**Sparsity:** per edge, couplings among \((\phi_a,\phi_b,c_a,c_b)\) for each species — block-bordered for 1D chains. Newton–Krylov avoids forming the full Jacobian if matrix-free JVPs are implemented from the same residual routine.

## Log-transform for concentrations

Let \(c_i = \exp(u_i)\) with \(u_i=\ln c_i\).

- **Positivity:** \(c>0\) built-in; avoids clamp-at-\(10^{-30}\) distorting Jacobians in the interior.
- **Residual:** rewrite NP flux in terms of \(u\) (exponential fitting / Slotboom form) so drift appears as \(\nabla u + (zF/RT)\nabla\Phi\); Jacobian entries involve \(c\,\partial(\cdot)/\partial u = c \cdot (\cdots)\).
- **Trade-off:** Poisson still couples through \(\rho_e \propto e^{u^+}-e^{u^-}\); Newton blocks become more nonlinear but often better conditioned for wide concentration ranges.

## f32 robustness: Bernoulli and when to use f64 inner solve

**Current implementation:** `bernoulli_b` uses `u.abs().exp()` for the ratio branch with Taylor near \(u=0\). For large \(|x|\), \(B(x)=x/(e^x-1)\) has **finite** limits (\(\to 0\) as \(x\to +\infty\), \(\to -x\) as \(x\to -\infty\)), but intermediate `exp` in **f32** overflows near \(|x|\gtrsim 88\), and even below that cancellation in `exp(x)-1` loses relative accuracy.

**Practical mitigations (Track 14):**

1. **Asymptotic branches** for \(|x|>x_{\text{cut}}\): use closed forms \(B(x)\sim 0\) (with correct next-order if needed for Jacobian) and \(B(x)\sim -x\) for large negative \(x\), avoiding `exp` of large magnitude.
2. **`log1p` / stable exponentials** where the literature formulation allows (e.g. rewrite SG coefficients in terms of inverse Bernoulli or sinh ratios).
3. **f64 inner solve** for: (i) Newton linear systems or Bernoulli assembly when \(|z F\Delta\phi/(RT)|\) can exceed moderate thresholds; (ii) verification / CI reference paths (pattern already used in acoustics: f32 simulation with f64 dense reference). Promote only the hot residual / Jacobian path that needs range; keep tensors f32 if desired for bandwidth, with explicit cast islands.

Module docs already flag: tight \(\Delta t\), smaller drift, or double precision until log-flux / exponential fitting exists.

## Discrete residuals (must match current Laplacian + SG)

For a backward–Euler implicit step, residuals should be evaluated with the **same** operators as production:

**Poisson:**  
\(R_\Phi = \mathcal{L}\Phi + \rho_e(c)/\varepsilon\) (interior), with Dirichlet rows pinned or residual zeroed at BC nodes. On the MVP chain, \(\mathcal{L}\) must match `TopologicalLaplacian::scalar_laplacian` / Thomas interior (`-2` on diagonal, `1` on off-diagonals for uniform unit spacing — scaled when mesh metrics enter the Laplacian).

**Species:**  
\(R_{c} = (c-c^n)/\Delta t + \nabla\!\cdot J_{\text{SG}}(\Phi,c)\) with \(J_{\text{SG}}\) identical to `solve_pnp_split_step_experimental_with_refs` edge assembly: harmonic mean \(D_e\), `h_inv = 1/\texttt{mesh_spacing}`, endpoint gathers, same `pe` and `bernoulli_b` mapping.

**Newton sanity:** \(\|R\|\) must drop across damped Newton iterations on the 1D chain before enabling long-horizon Debye-length gates; mass conservation on closed graphs should use the same `primal_divergence` convention (zero row-sum property per `dec_primal` docs).

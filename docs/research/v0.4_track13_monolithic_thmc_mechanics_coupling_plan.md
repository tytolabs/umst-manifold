# Track 13 — Monolithic THMC + mechanics coupling (v0.4 research plan)

**Workspace:** `umst-manifold` · **Lane:** `solvers::thmc` (`thmc-coupled`).  
**Companion memos:** Newton / JFNK notation — [`v0.4_track13_monolithic_newton_thmc.md`](v0.4_track13_monolithic_newton_thmc.md); detailed \(R_u\) symbolics and long-form phases — [`thmc_monolithic_mechanics_coupling_plan.md`](thmc_monolithic_mechanics_coupling_plan.md).  
**Status surface:** [`Solver-Status.md`](../Solver-Status.md) — `solvers::thmc` row and **Solver lanes — THMC**.

This document is the **single executive plan** for closing the gap between **operator-split** `ThmcSolver::step` / `step_experimental` and a **monolithic** implicit step \(R(U^{n+1})=0\) on stacked unknowns including quasi-static bar-network displacement \(\mathbf u\in\mathbb{R}^{3N}\).

**Staggered vs implicit stacks:** The **implicit Newton** paths in `thmc_residual.rs` never replace the full step: `ThmcImplicitTAlphaNewtonConfig` only drives `ThmcImplicitEulerThermalHydrationResidual::damped_newton_iterations` inside the split loop. The **\((T,h,\alpha)\)** assembler is exercised in verification tests but is **not** wired as the sole root finder for a full timestep (see `thmc_implicit_euler_t_h_alpha_*` and comments in [`tests/verification/thmc_drying_shrinkage.rs`](../../tests/verification/thmc_drying_shrinkage.rs)).

### 1.2 Slice `28d9c11` (what shipped vs gaps)

**Shipped in the sense of Track 13 chemistry transport:** backward-Euler **stacked** residuals for **\((T,\alpha)\)** and **\((T,h,\alpha)\)** on the graph Laplacian, with optional damped Newton on the scalar blocks (small DOF cap, batch 1), consistent with the milestone described in commit **`28d9c11`**: **\(R_T, R_h, R_\alpha\)** assembled together **without** treating bar equilibrium as part of the same Newton residual.

**Outstanding for “full monolithic THMC + mechanics”:**

- No single Newton loop over **\([\mathrm{vec}(T);\mathrm{vec}(h);\mathrm{vec}(\alpha);\mathrm{vec}(\mathbf u)]\)** with a Jacobian that includes **\(\partial R_u / \partial \alpha\)** (stiffness modulation) and transport–mechanics cross terms.
- `ThmcSolver` still ends each subpass with a **completed** `VectorMechanicsSolver::solve_equilibrium` rather than leaving \(\mathbf u\) as free variables inside one \(R=0\) solve.
- Humidity **drying closure** at the last node (algebraic update in the split step) is not yet encoded as part of \(R_h\) for a monolithic root (see [`thmc_monolithic_mechanics_coupling_plan.md`](thmc_monolithic_mechanics_coupling_plan.md) §2.2).

### 1.3 Phase 1 vertical slice (in-tree after this track)

**Bookkeeping + verification only** (no `ThmcSolver` monolithic mode yet):

1. **Placeholder mechanics block** for flat stacking: \(R_u = m(\mathbf u - \mathbf u^n)\) with configurable \(m =\) `mechanics_placeholder_mass` — documents field-major tail length and L² aggregation; **not** quasi-static equilibrium (see struct rustdoc on `ThmcImplicitEulerThermalHumidityHydrationResidual`). APIs: `assemble_with_mechanics_placeholder_r_u`, `stacked_flat_residual_field_major`, `residual_l2_including_mechanics_placeholder`.
2. **Quasi-static \(R_u\) evaluation** at a trial displacement: `evaluate_quasi_static_r_u` delegates to `VectorMechanicsSolver::projected_bar_equilibrium_residual` with the same \(\alpha \mapsto E\) scaling rule as `step_experimental`. CI: `thmc_r_u_zero_at_solved_equilibrium_two_node_chain` checks \(\|R_u(\mathbf u^\star)\|\) small at the converged `solve_equilibrium` solution.

**Tests:** `thmc_implicit_euler_t_h_alpha_u_placeholder_r_u_and_flat_layout_two_nodes`, `thmc_r_u_zero_at_solved_equilibrium_two_node_chain` in [`tests/verification/thmc_drying_shrinkage.rs`](../../tests/verification/thmc_drying_shrinkage.rs).

## 2. Physics (stacked unknowns and \(R_u\))

### 2.1 Agreed field-major ordering

Align with the existing **\((T,\alpha)\)** dense Newton convention and [`ThmcMonolithicImplicitUnknownLayout`](../../src/physics/solvers/thmc_residual.rs):

\[
U_{\mathrm{flat}} = \bigl[\mathrm{vec}(T),\ \mathrm{vec}(h),\ \mathrm{vec}(\alpha),\ \mathrm{vec}(\mathbf u)\bigr],
\]

per batch slice, with \(\mathbf u\) nodal \([u_x,u_y,u_z]\) contiguous per node in node index order. **Alternative** node-major layout is discussed in [`v0.4_track13_monolithic_newton_thmc.md`](v0.4_track13_monolithic_newton_thmc.md) §1; any switch must update the const layout helper and all FD stacks in lockstep.

### 2.2 Shrinkage and effective stress (Track 13 memo alignment)

Hydration-dependent stiffness and **notional** shrinkage strain hooks live in [`thmc.rs`](../../src/physics/solvers/thmc.rs) (`mc2010_style_notional_shrink_strain`, `shrink_strain_from_saturation_loss`, drying band tests). For monolithic \(R_u\), shrinkage should enter as either:

- an **eigenstrain** increment \(\Delta\varepsilon_{\mathrm{shr}}(h,\alpha,\ldots)\) folded into nodal loads or a modified **compatibility** operator, or  
- a **stress-like** body term consistent with the bar-network kinematics already used for fracture coupling (`strain_tensor_from_bar_network_displacement`).

The detailed coupling options and splitting-error notes are in [`thmc_monolithic_mechanics_coupling_plan.md`](thmc_monolithic_mechanics_coupling_plan.md) §2.4–2.5 and §3.

### 2.3 \(R_u\) for quasi-static bar network

Target residual (conceptual):

\[
R_u(\mathbf u;\alpha,d) = P\bigl(\mathbf f_{\mathrm{ext}} - \mathbf f_{\mathrm{int}}(\mathbf u; E(\alpha), d)\bigr),
\]

with \(P\) the Dirichlet projector from `displacement_bc_mask`. **No** \((\mathbf u^{n+1}-\mathbf u^n)/\Delta t\) term in the shipped quasi-static contract ([`Solver-Status.md`](../Solver-Status.md) verification scope item **#10**).

## 3. Numerics

### 3.1 Monolithic Newton

- **Assembly:** Reuse per-block residual routines (`assemble` for scalars; `evaluate_quasi_static_r_u` or inlined `packed_bar_network_equilibrium` semantics for mechanics) into one vector \(R\).
- **Jacobian:** For **small** verification graphs, **dense column FD** on the full stacked \(U\) is the lowest-friction extension of [`ThmcImplicitEulerThermalHydrationResidual::one_damped_newton_step`](../../src/physics/solvers/thmc_residual.rs). For production-sized graphs, move to **JFNK** (matrix-free JVPs) per [`v0.4_track13_monolithic_newton_thmc.md`](v0.4_track13_monolithic_newton_thmc.md) §1.

### 3.2 Jacobian structure (block sparsity)

Block layout:

| Block | Sparsity sketch |
|-------|------------------|
| \(J_{TT}, J_{hh}\) | Graph Laplacian patterns (same as scalar transport) |
| \(J_{\alpha\alpha}, J_{T\alpha}, J_{\alpha T}\) | Mostly nodal / low-stencil from \(\dot\alpha(\alpha,T)\) and exothermic source |
| \(J_{uu}\) | Bar-network stiffness pattern from [`mechanics.rs`](../../src/physics/mechanics.rs) |
| \(J_{u\alpha}, J_{\alpha u}\) | From \(E(\alpha)\) on edges / nodal averaging — **must** appear for true coupling |

### 3.3 Preconditioner sketch

Block Jacobi or block Gauss–Seidel: approximate inverse using **one** Laplacian solve each for \(T\) and \(h\) (or Jacobi on diagonals), nodal scaling for \(\alpha\), existing mechanics PCG on \(J_{uu}\) as a **physics-based** preconditioner. Schur approximations only for preconditioning, not for replacing \(R\).

### 3.4 Burn / autodiff boundaries

Residuals today are assembled with explicit Burn tensor ops. **Full-graph AD** through `solve_equilibrium` (iterative linear solve) is not a practical way to obtain \(J\). Expect **FD or JVP probes** on the **assembled** \(R_u\) at fixed PCG tolerance, or hand-derived **sparse tangents** for \(J_{uu}\) and \(J_{u\alpha}\) with AD only on nodal closures (e.g. \(\dot\alpha\)). Document numerical differentiation tolerances next to PCG exits to avoid false coupling noise.

## 4. Phased roadmap and acceptance tests

| Phase | Goal | Acceptance (tests / gates) |
|-------|------|----------------------------|
| **1** | Stacked unknown bookkeeping + **evaluable** \(R_u\) at trial \(\mathbf u\); placeholder tail for flat length / L² | `thmc_implicit_euler_t_h_alpha_u_placeholder_r_u_and_flat_layout_two_nodes`; `thmc_r_u_zero_at_solved_equilibrium_two_node_chain`; `ThmcMonolithicImplicitUnknownLayout` matches `stacked_flat_residual_field_major` length |
| **2** | Assemble **true** \(R_u\) into the same `Vec<f32>` stack as \((R_T,R_h,R_\alpha)\) (no placeholder); optional dense FD Jacobian on **tiny** graphs for **one** Newton step smoke | New test: stacked \(\|R\|_2\) decreases for one damped Newton on \((T,h,\alpha,\mathbf u)\) with \(n(F_T+F_h+F_\alpha+3)\le\) cap; document PCG/FD tolerance coupling |
| **3** | Sparse / block-aware tangent for \(J_{uu}\) and \(J_{u\alpha}\) (or JFNK JVPs); preconditioner prototype | Unit tests on 2–3 node chains: Jacobian–vector vs FD band; optional ignored medium-\(N\) smoke |
| **4** | `ThmcSolver` config path: monolithic step **instead of** split when graph caps allow; clear `Err` when unsupported | Integration test behind feature: one step monolithic vs split reference on toy graph; update `Solver-Status.md` |
| **5** | Shrinkage / eigenstrain in \(R_u\); optional within-step \(u\!\leftrightarrow\!d\) stagger | Extend shrinkage verification; fracture memo §7 alignment |

### Out of scope (explicit)

- **Full AT2 fracture** monolithically coupled in \(R\) (track 12 staggered scope remains primary).
- **General 3D solid** transient \(M\ddot u + C\dot u + Ku\) (see Solver-Status row **#10**).
- **Pore chemistry / sorption isotherms** beyond single \(\alpha\) unless added as new blocks.

## 5. Risks

| Risk | Mitigation |
|------|------------|
| **Ill-conditioning** when \(E(\alpha)\to 0\) or damage masks degenerate edges | Keep \(\alpha\) lower clamp consistent with `step_experimental`; document Jacobian scaling / row equilibration |
| **DOF layout bugs** between scalar flatten and \(\mathbf u\) tail | Single source: `ThmcMonolithicImplicitUnknownLayout`; property tests on `stacked_flat_residual_field_major` length and hand permutations |
| **CI runtime** for dense FD on enlarged stacks | Hard cap DOFs (mirror `MAX_DOFS == 64` pattern); gate full-stack Newton behind `solver-experimental` + small \(n\) only |
| **False Newton progress** when \(R_u\) uses inexact PCG | Tie FD probe and residual checks to stricter inner tolerances on verification paths |

# Track 16 — Virial / LJ bridge statistical mechanics (v0.4 research memo)

## Purpose

Replace the **placeholder** Lennard-Jones → continuum map in `solvers::statistical_mechanics::upscale_potentials` with a **reference-grounded** bridge: bulk modulus \(K(\rho,T)\) from statistical mechanics (virial or calibrated EOS), and grand-canonical surface energy \(\gamma_{\mathrm{gc}}\) from an interface-resolved route. This memo fixes physics targets, external references, and an implementation-facing API contract without modifying solver status tables elsewhere.

## Current code baseline (locked contracts)

- **`StatisticalBridge::upscale_potentials` / `upscale_potentials`** accept `[B, 2]` tensors with columns \((\varepsilon, \sigma)\) and return `[B, 1]` bulk modulus \(K\) and `[B, 1]` \(\gamma_{\mathrm{gc}}\).
- **Placeholder mapping:** \(K = C_K \, \varepsilon / \sigma^{3}\), \(\gamma_{\mathrm{gc}} = C_\gamma \, \varepsilon / \sigma^{2}\) with \(C_K = C_\gamma = 1\) (`ANALYTIC_*_SCALE`). Differentiable in Burn; **not** a physical EOS.
- **`tests/verification/statmech_lj_bridge_contract.rs`** asserts only this analytic scaling non-regression; it explicitly states this is **not** virial or coexistence physics.

## Physics targets

### 1. Bulk modulus \(K(\rho,T)\) — virial route and EOS bridge

**Virial / MD definitions (conceptual target):**

- For a homogeneous LJ fluid at number density \(\rho = N/V\) and temperature \(T\) (in consistent reduced or SI units), the **pressure** follows from the virial theorem (pair potentials):

  \[
  P = \rho k_B T - \frac{1}{3V} \left\langle \sum_{i<j} \mathbf{r}_{ij} \cdot \mathbf{F}_{ij} \right\rangle
  \]

  with forces \(\mathbf{F}_{ij}\) from the truncated/shifted LJ convention actually used in simulation.

- The **isothermal bulk modulus** is

  \[
  K_T = -V \left(\frac{\partial P}{\partial V}\right)_{T,N}
      = \rho \left(\frac{\partial P}{\partial \rho}\right)_{T}
  \]

  Evaluated either by numerical differentiation of \(P(\rho)\) along an isotherm (EOS tabulation), or from fluctuation formulae in \(NPT\) where applicable.

**Johnson–Zollweg–Gubbins Lennard-Jones EOS (reference closure):**

- J. K. Johnson, J. A. Zollweg, K. E. Gubbins, *The Lennard-Jones equation of state revisited*, **Mol. Phys.** **78**, 591–618 (1993). doi: [10.1080/00268979300100411](https://doi.org/10.1080/00268979300100411).

This work parametrizes an MBWR-style EOS for the LJ fluid, correlating pressure and energy over a wide \((\rho,T)\) range and vapor–liquid coexistence. **Implementation strategy:** treat tabulated \(P(\rho,T)\) or \(\mu(\rho,T)\) from this EOS (or equivalent modern tables/codes, e.g. teqp’s `LJ126Johnson1993` family) as **gold labels** for validating any differentiable surrogate before swapping the placeholder.

### 2. Surface tension \(\gamma\) — Kirkwood–Buff vs planar slab MD; WCA reference

**Grand-canonical surface energy \(\gamma_{\mathrm{gc}}\)** (as named in `statistical_mechanics` docs) should align with a precise interface definition:

| Route | Idea | Notes |
|-------|------|--------|
| **Planar interface MD** | Simulate liquid–vapor or liquid–liquid coexistence; \(\gamma\) from integral of normal vs lateral stress mismatch (IK / virial of pressure tensor) or from capillary wave / profile methods consistent with the same potential | Direct, matches “interface widening / coexistence” language in module docs |
| **Kirkwood–Buff / local structure** | Excess free energy or cluster/number fluctuations tied to interfacial excess quantities | Use when matching solvation or inhomogeneous density field around an interface; must be mapped to the same \(\gamma\) definition as the DEC cartridge |

**WCA (Weeks–Chandler–Andersen) reference:** split the LJ potential into repulsive and attractive parts. A common pattern is: **repulsive WCA reference fluid** for structure, **attractive perturbation** for free energy (or direct LJ for both, with clear reporting). Any \(\gamma\) or \(K\) comparison must state **which WCA convention** and **which long-range treatment** (cutoff, shift, LRC) was used, so the continuum side is not compared to an inconsistent microstate ensemble.

## API contract (v0.4+ design)

The present function only takes \((\varepsilon,\sigma)\). A **virial / EOS bridge** must thread **thermodynamic state and MD protocol** into the same tensor API (or a parallel `StatisticalBridge` method) so results are reproducible and testable.

| Input / config | Role |
|----------------|------|
| **State** | Number density \(\rho\) (or molar / mass density in cartridge units) and temperature \(T\) (or reduced \(T^* = k_B T / \varepsilon\)) |
| **LJ parameters** | \(\varepsilon\), \(\sigma\) (per species or mixing rules if multi-site later) |
| **Cutoffs** | \(r_c / \sigma\), whether potential is **cut-only**, **cut-and-shifted**, or **LJ with tail correction**; must match the reference EOS or MD column used for labels |
| **Ensemble for \(\gamma_{\mathrm{gc}}\)** | e.g. **NVT** slab with fixed area vs **NPT** with fluctuating area; **\(\mu VT\)** if truly grand-canonical; document which definition of \(\gamma\) (IK tensor, etc.) |
| **Outputs** | Same as today: **scalar** \(K\) and \(\gamma_{\mathrm{gc}}\) per batch row, or extended batch channels if multiple states are passed |

**Differentiability (Burn):** the placeholder path remains the gradient-friendly fallback until the calibrated map is implemented as **differentiable ops** (table lookup + smooth interpolation, or a neural/proxy EOS with bounded derivatives). Frozen discrete tables alone need interpolation layers for autodiff through training.

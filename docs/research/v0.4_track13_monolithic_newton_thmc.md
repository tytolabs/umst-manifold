## 1. Knoll–Keyes JFNK and block preconditioning

**Jacobian-free Newton–Krylov (JFNK)** following Knoll & Keyes (*J. Comput. Phys.*, 2004): solve each Newton correction \(\delta U\) from

\[
J(U^k)\,\delta U = -R(U^k), \qquad J = \frac{\partial R}{\partial U},
\]

using a Krylov method (GMRES/FGMRES) that only needs **Jacobian–vector products** \(J v\), obtained by directional derivatives of \(R\) (finite differences on the residual map or reverse-mode AD on a scalar probe).

**Why JFNK here:** The fully coupled THMC residual touches transport on edges (sparse graph structure), nonlinear nodal chemistry, and a mechanics equilibrium solve. Forming a dense Jacobian is prohibitive; forming sparse blocks is viable but heavy for a first milestone—JFNK reuses the same residual assembly as the implicit step.

**Block preconditioning** for the partitioned unknowns **\(U = (T,\,h,\,\alpha,\,u)\)** (thermal, hydrologic, hydration degree, displacement):

- **Physical splitting:** Approximate \(J\) by a block \(4\times 4\) structure matching the physics:
  - \(J_{TT}\): thermal diffusion + local ∂/∂T of sources (exothermic term).
  - \(J_{hh}\): humidity diffusion + drying boundary relaxation.
  - \(J_{\alpha\alpha}\): hydration kinetics diagonal in \(\alpha\) (plus clipping semantics at bounds).
  - \(J_{uu}\): tangent stiffness from mechanics (elasticity with \(E(\alpha)\)).
  - Off-blocks: \(J_{T\alpha}, J_{\alpha T}, J_{u\alpha}\) (and humidity–transport cross terms if closure adds them).

- **Preconditioner choices (conceptual):**
  - **Block Jacobi / block Gauss–Seidel:** Invert (or approximate invert) diagonal blocks only—e.g. symmetric positive-definite Laplacian-style solves for \(T\) and \(h\), nodal scalings for \(\alpha\), existing `VectorMechanicsSolver` linearization for \(u\).
  - **Schur complement approximations:** If mechanics–transport coupling is weak in one regime, use an approximate Schur on the \(u\) block or eliminate \(\alpha\) in a reduced model for preconditioning only (not for the final residual).

- **Field ordering:** For Krylov, choose either **field-major** \([T_1..T_N, h_1..h_N, \ldots]\) or **node-major** \([T_1,h_1,\alpha_1,u_{1:3}, \ldots]\). Node-major can improve cache locality on unstructured graphs; field-major simplifies reusing single-physics solvers as blocks.

## 2. Residual \(R(U)=0\) for implicit Euler; sparsity pattern

For backward Euler with time step \(\Delta t\) and previous state \(U^n\), the **coupled implicit step** seeks \(U^{n+1}\) such that

\[
R(U^{n+1}) = U^{n+1} - U^n - \Delta t\, F(U^{n+1}, U^n) = 0
\]

where \(F\) collects semi-discrete RHS: diffusion operators, reaction sources, and constraint of quasi-static equilibrium for \(u\) (possibly as a sub-equation \(R_u = 0\) written in residual form consistent with the implicit step).

**Aligning with the shipped step (diagnostic baseline vs opt-in block):** By default, `ThmcSolver::step` uses explicit Euler for \(T\) and \(\alpha\) (with Arrhenius kinetics), then \(h\), then quasi-static \(u\) when enabled. With `implicit_t_alpha_newton: Some(…)`, the **first** sub-step each outer pass is backward-Euler **\((T,\alpha)\)** Newton instead of that explicit pair; \(h\) and \(u\) remain on the split path. Diagnostic residuals after each pass still measure \(|T_{\mathrm{new}} - T_{\mathrm{old}} - \Delta t\,\mathcal{L}_T|\)-style mismatches where applicable. The **monolithic** target is a single \(R\) over all coupled unknowns whose root is the fully implicit update.

**Sparsity:**

- **Graph Laplacian blocks** (\(T\), \(h\)): Stencil is **edge-supported**—nonzeros couple nodes sharing an edge in `edges_b1`, modulated by damage masks on coefficients. Pattern matches the topology (similar to a graph Laplacian with heterogeneous coefficients).

- **Nodal Arrhenius chemistry:** \(\dot\alpha = f(\alpha, T)\) is **local per node** in the current model (temperature broadcast from thermal channel). Jacobian coupling \(\partial R_\alpha/\partial T\) is **nodal diagonal** in space (dense in the small channel dimension if multi-channel \(\alpha\)).

- **Exothermic coupling:** \(\Delta T \propto \dot\alpha\) introduces **\(\partial R_T/\partial \alpha\)** block entries (nodal).

- **Mechanics:** Equilibrium couples **displacements** across the elastic network; **\(E(\alpha)\)** ties stiffness to hydration → **\(\partial R_u/\partial \alpha\)** (and indirectly \(\partial R_\alpha/\partial u\) if chemistry depended on strain—currently not in the baseline path).

## 3. Jacobian blocks of interest

| Block | Role |
|--------|------|
| \(\partial R_\alpha / \partial T\) | Arrhenius factor \(\exp(-E_a/(RT))\) and optional \(T\)-boost multiplier → strong temperature sensitivity of hydration rate. |
| \(\partial R_T / \partial \alpha\) | Exothermic source proportional to \(\dot\alpha(\alpha,T)\) → chain rule through \(\dot\alpha\). |
| \(\partial R_T / \partial T\) | Thermal diffusion (Laplacian) + local derivative of exothermic term w.r.t. \(T\). |
| \(\partial R_u / \partial u\) | Elastic tangent (bar/network model used by `VectorMechanicsSolver`). |
| \(\partial R_u / \partial \alpha\) | **Mechanics through \(E(\alpha)\)** — current code uses \(E \propto \alpha\) at nodes (`stiffness_e = α · stiffness_e_scale_pa`), so tangent stiffness shifts with \(\alpha\). |

Cross-block sparsity for \((T,\alpha)\) is **nodal-local** in the shipped closure; \((u,\alpha)\) couples through **material stiffness** on the structural graph.

## Appendix — § Implementation blueprint

This section is the **detailed design** called for in [`Solver-Status.md`](../Solver-Status.md) **DEFERRAL — THMC** (deferred monolithic Newton / JFNK column): full stacked implicit Newton–Krylov in one PR is **out of scope**; the goal here is a **single, implementation-ready contract** for a follow-on PR series.

**Scope boundary (unchanged from DEFERRAL):** Shipped lane remains `ThmcImplicitTAlphaNewtonConfig` on **\((T,\alpha)\)** only, with humidity and mechanics on the **split** path. The blueprint below describes the **target** \(R(U^{n+1})=0\) for **\((T,h,\alpha,u)\)** (and notes where **damage** \(d\) stays outside the same root for the v0.4 fracture contract).

### A. Unknown vector layout

**State tensors (Burn):** [`ThmcState`](../../src/physics/solvers/thmc.rs) already fixes per-field shapes:

| Field | Tensor role | Shape |
|--------|-------------|--------|
| \(T\) | `thermal.temperature` | `[B, N, F_T]` |
| \(h\) | `hydro.humidity` | `[B, N, F_h]` |
| \(\alpha\) | `chemical.hydration_alpha` | `[B, N, F_\alpha]` |
| \(\mathbf u\) | `mechanical.displacement` | `[B, N, 3]` |

**Recommended flattened unknown for Krylov (field-major):** One vector \(U\in\mathbb{R}^{B\cdot M}\) with **no coupling across batch index** — each batch slice is an independent nonlinear root. For batch \(b\),

\[
U_b = \bigl[\mathrm{vec}(T_{b,:,:})\ \|\ \mathrm{vec}(h_{b,:,:})\ \|\ \mathrm{vec}(\alpha_{b,:,:})\ \|\ \mathrm{vec}(\mathbf u_{b,:,:})\bigr],
\]

with each `vec` in **row-major** order over nodes \(0..N-1\) then feature / component index. **Total DOFs per batch:**

\[
M = N F_T + N F_h + N F_\alpha + 3N.
\]

**Rationale:** Matches the existing **\((T,\alpha)\)** dense FD stacking in [`ThmcImplicitEulerThermalHydrationResidual::one_damped_newton_step`](../../src/physics/solvers/thmc_residual.rs) (thermal block first, then chemical), so the first implementation of a larger stack extends the same convention. **Alternative (node-major):** \([T_{b,i,:}, h_{b,i,:}, \alpha_{b,i,:}, u_{b,i,:}]\) per node \(i\); better cache locality on unstructured graphs but harder to reuse Laplacian-only preconditioners as literal sub-blocks.

**Not in \(U\) for v0.4 fracture contract:** `damage` remains the **post-pass** `PhaseFieldFractureSolver::update_damage` input unless a later memo explicitly adds a **within-step** \(u\!\leftrightarrow\!d\) stagger (DEFERRAL — Fracture / phase brief R3.1). For a **pure transport + mechanics** monolith, treat \(d\) as **frozen** at \(d^n\) inside \(R\) (same as today’s `damage_m` mask for Laplacian coefficients).

**Code anchor (ZST, no runtime):** [`ThmcMonolithicImplicitUnknownLayout`](../../src/physics/solvers/thmc_residual.rs) carries `const fn field_major_stacked_dof_count(...)` so layout arithmetic stays **one source of truth** next to [`ResidualThmc`](../../src/physics/solvers/thmc_residual.rs).

### B. Residual blocks (backward Euler)

Seek \(U^{n+1}\) with \(R(U^{n+1})=0\) and \(R = [R_T; R_h; R_\alpha; R_u]\) aligned with the same field-major stack.

1. **Thermal (implicit BE):** Same structure as today’s Laplacian + exothermic source, but **evaluated at** \(T^{n+1}, \alpha^{n+1}\):
   \[
   R_T = T^{n+1} - T^n - \Delta t\,\bigl(\mathcal{L}_T(T^{n+1}; d^n) + q_{\mathrm{exo}}\,\dot\alpha(\alpha^{n+1}, T^{n+1})\bigr).
   \]
   \(\mathcal{L}_T\) is the masked graph Laplacian already used in `ThmcSolver` / [`TopologicalLaplacian`](../../src/physics/laplacian.rs).

2. **Humidity (implicit BE):** Replace the **explicit** humidity substep with a root of
   \[
   R_h = h^{n+1} - h^n - \Delta t\,\mathcal{L}_h(h^{n+1}; d^n) + \text{(optional evaporation sink at facet nodes)}.
   \]
   The **drying last-node sink** in the shipped solver is a **post-Laplacian algebraic closure**; in the monolith it becomes part of \(R_h\) (or an equivalent slack variable) so the humidity equation is **consistent** with the implicit temperature/hydration map.

3. **Hydration \(\alpha\) (implicit BE):**
   \[
   R_\alpha = \alpha^{n+1} - \alpha^n - \Delta t\,\dot\alpha(\alpha^{n+1}, T^{n+1}).
   \]
   **Clipping:** Either **smooth penalization** inside \(\dot\alpha\) near \([0,1]\) or **active-set** on bounds; the explicit path uses `.clamp(0,1)` after the update — the monolithic residual should document the same **invariant** (e.g. Fischer–Burmeister for bound constraints, or clamp only in the **line search**).

4. **Mechanics (quasi-static equilibrium at \(n+1\)):** Bar / network residual in **displacement form**
   \[
   R_u(\mathbf u^{n+1}, \alpha^{n+1}) = \mathbf{f}_{\mathrm{int}}(\mathbf u^{n+1}; E(\alpha^{n+1}), \ldots) - \mathbf{f}_{\mathrm{ext}} = 0,
   \]
   with \(E \propto \alpha\) at nodes as in current `stiffness_e` wiring. This is **not** a time-difference equation; it is a **simultaneous** equilibrium constraint coupled to \(\alpha^{n+1}\) (and optionally to \(h,T\) if constitutive extensions add them).

**Stacked norm for convergence:** \(\|R\| = \sqrt{\|R_T\|_2^2 + \|R_h\|_2^2 + \|R_\alpha\|_2^2 + \|R_u\|_2^2}\) (same weighting per DOF; later: block-scaled norms for preconditioned GMRES).

### C. Jacobian structure (Newton / JFNK)

**Dense path (tiny graphs only):** Forward the existing FD pattern from `one_damped_newton_step` to the **full** \(M\)-vector; cap \(M\) or use **batched** independent small graphs.

**Production path — Jacobian-free Newton–Krylov:** GMRES on \(J\delta = -R\) with matrix-free \(Jv\) via **one-sided difference**
\[
Jv \approx \frac{R(U + \varepsilon v) - R(U)}{\varepsilon}
\]
or tangent-mode AD if the graph is small enough. **Block structure (conceptual \(4\times 4\)):**

| | \(\partial/\partial T\) | \(\partial/\partial h\) | \(\partial/\partial \alpha\) | \(\partial/\partial u\) |
|--|:---:|:---:|:---:|:---:|
| \(R_T\) | Laplacian + local exo derivative | 0 (unless extended) | \(\partial R_T/\partial\alpha\) via \(\dot\alpha\) | 0 |
| \(R_h\) | 0 (unless extended) | Laplacian + sink derivatives | 0 (unless sorption) | 0 |
| \(R_\alpha\) | \(\partial R_\alpha/\partial T\) (Arrhenius) | 0 | diagonal + rate Jacobian | 0 (unless strain-dependent kinetics) |
| \(R_u\) | 0 | 0 | \(\partial f_{\mathrm{int}}/\partial\alpha\) (tangent stiffness w.r.t. \(E(\alpha)\)) | \(K_T\) (elastic tangent) |

**Preconditioner (first usable):** Block Jacobi: (1) symmetric Laplacian approximations for \(T\) and \(h\); (2) nodal scaling / ILU on \(\alpha\); (3) reuse **existing** mechanics linear solve as approximate \(K_T^{-1}\). Schur approximations only if \(h\)–\(T\) coupling is added.

### D. Batched Burn constraints

- **Batch axis:** All participating tensors share the same `B`; **no** residual couples batch \(b\) to \(b'\). Each Newton/Krylov solve is **embarrassingly parallel** over \(b\).

- **Topology:** `edges_b1` and masks are **identical** across batch slices (same graph for all \(b\)); only nodal **values** differ. JVP assembly loops batch **outside** sparse edge gathers.

- **Shape / device:** All blocks live on the same `Device` as `state`; Krylov work vectors are `[B, N, F]` reshapes of flat slices, not mixed devices.

- **Channel broadcast (thermal \(\to\) \(\alpha\)):** Preserve the rule in [`ThmcImplicitEulerThermalHydrationResidual::assemble`](../../src/physics/solvers/thmc_residual.rs): if \(F_\alpha>1\) but thermal is broadcast from channel 0, document the same **slice/expand** in the monolithic \(R_\alpha\) and in \(Jv\).

- **Verification caps:** Keep a **hard `MAX_DOFS`** (or per-batch cap) for **dense** Jacobian debug paths; production JFNK does not need a dense \(M\times M\) matrix.

- **Fracture / damage:** When SI `[N,3]` embedding is active, \(\varepsilon(\mathbf u)\) for damage update remains **post-mechanics** in the **split** product; the monolith’s \(R_u=0\) still delivers the \(\mathbf u^{n+1}\) that feeds that kinematic chain **after** the coupled root — document ordering: solve \(R=0\) \(\to\) optional `update_damage` with `strain_tensor_from_bar_network_displacement` (same as today).

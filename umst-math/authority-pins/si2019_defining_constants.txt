# SI 2019 defining constants used by umst-manifold solvers (exact by definition)
# Source: BIPM, The International System of Units (SI Brochure), 9th edition (2019), Table 1
# https://www.bipm.org/en/publications/si-brochure
symbol: c
name: speed of light in vacuum
value_SI: 299792458
unit: m/s
uncertainty: 0 (exact)

symbol: N_A
name: Avogadro constant
value_SI: 6.02214076e23
unit: 1/mol
uncertainty: 0 (exact)

symbol: k
name: Boltzmann constant
value_SI: 1.380649e-23
unit: J/K
uncertainty: 0 (exact)

symbol: R
name: molar gas constant
derivation: R = N_A * k
value_SI: 8.31446261815324
unit: J/(mol K)
uncertainty: 0 (exact product of two exact constants)
